# 回复清理（astrbot_plugin_reply_cleaner）

把模型输出里**不该发出去的东西**清掉，**不改人格提示词**（改提示词模型经常不听）。

## 为什么单独做这个

很多人格习惯每条消息都以「……」开头，发出去显得每句都欲言又止：

```
……行吧行吧           →   行吧行吧
……这下真得去忙了       →   这下真得去忙了
```

在人格提示词里写「不要以省略号开头」往往没效果，所以这里用规则**在发送前**直接清掉。

## 功能（都可单独开关）

| 功能 | 配置 | 默认 | 说明 |
|---|---|---|---|
| **去掉开头标记** ⭐ | `strip_leading_marks` / `leading_marks` | 开 / `……` | 只去掉**消息开头**连续出现的这些字符，不动中间内容 |
| 去掉思维链标签 | `strip_think_tags` | 开 | 清掉 `<think>`/`<thinking>`/`<reasoning>`/`<analysis>` 等，防止推理过程漏进正文 |
| 去掉零宽字符 | `strip_zero_width` | 开 | U+200B/200C/200D/FEFF 这类看不见的字符会搞得排版诡异 |
| 合并重复标点 | `collapse_punctuation` | 关 | `。。。`→`。`、`？？？`→`？` |
| 去掉自称前缀 | `strip_self_prefix` | 关 | 开头的 `AI：`、`助手：`、`机器人：` |
| 群聊 / 私聊开关 | `group_enable` / `private_enable` | 都开 | |
| 会话黑名单 | `blacklist` | 空 | 填 群号 / 用户号 / 完整会话标识 |

## 安全设计

- 只处理**纯文本的模型回复**；带图片、@、引用的消息一律不动
- **清理后如果整条变成空的，会自动还原原文** —— 绝不发出空消息
- 用 `priority=100` 注册，**先于分段类插件执行**
  （否则开头的「……」会先被分段插件切成一条独立消息，就清不掉了）

## 和 `astrbot_plugin_reply_trim` 的关系

两者可以同时装，互不冲突：

| 插件 | 职责 |
|---|---|
| **reply_cleaner**（本插件） | 清理内容：开头标记、思维链、零宽字符等 |
| reply_trim | 去掉首尾空白 + 按标点/换行分段发送 |

本插件优先级更高，所以顺序是：**先清理 → 再分段**。

## 安装

把本目录放到 `AstrBot/data/plugins/astrbot_plugin_reply_cleaner/`，重启 AstrBot 或热重载插件。

> ⚠️ 如果 AstrBot 配置里设置了 `plugin_set`（插件白名单，不是 `["*"]`），必须把本插件加进名单，否则不会生效。
